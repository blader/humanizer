# Humanizer（中文版）

[![skills.sh installs](https://skills.sh/b/blader/humanizer)](https://skills.sh/blader/humanizer)

Humanizer 会把带有「AI 味」的文本改写成像真人写的一样，同时不改变原文想表达的意思。因为它只是一个 Markdown 文件，所以适用于所有支持 Skills 的 AI 代理。

> 本文件是 [Humanizer](https://github.com/blader/humanizer) 官方 README 的中文翻译，方便中文用户快速上手。原文与更新以英文版 README 为准。

## 安装

使用 Skills CLI 安装：

```bash
npx skills add blader/humanizer --global
```

去掉 `--global` 则只安装到当前项目。加 `--agent <名称>` 或 `--agent '*'` 可以选择哪些代理接收它，然后重载它们的 skills。安装后通过 `/humanizer` 调用。

Claude Code 2.1.142 或更高版本也可以改用插件方式安装：

```text
/plugin marketplace add blader/humanizer
/plugin install humanizer@humanizer
```

插件通过 `/humanizer:humanizer` 调用。

在 Claude Desktop 中：把本仓库下载为 ZIP，作为 skill 上传。手动安装时，把 `SKILL.md` 复制到代理的 skill 目录即可。

## 用法

直接调用：

```
/humanizer

[在这里粘贴你的文本]
```

或者用自然语言提问：

```
请帮我把这段文本写得更像真人： [你的文本]
```

要改写某个文件，直接给出路径：

```
请把 docs/launch-post.md 中的散文部分 humanize 一下
```

### 匹配你的文风

如果你希望改写结果更像你自己的风格，可以附上一段范文：

```
/humanizer

这是我的一段写作样本，用于匹配文风：
[粘贴 2-3 段你自己的文字]

现在请改写这段 AI 文本：
[粘贴需要改写的 AI 文本]
```

Humanizer 会模仿样本的节奏、用词、标点和你特有的行文习惯（包括你习惯使用的破折号）。

## 工作原理

语言模型只会生成「概率上最可能出现的下一个词」，所以默认它会选择最贴合最广泛读者和主题的表达。而真人会为一个具体读者、一个具体主题做选择。Humanizer 寻找的每一种「AI 痕迹」，本质上都是这种「默认选择」的一种表现：用一个句子宣告重要性而不是增加事实、按规则堆砌节奏或排版、把普通事实包装成关键论断、或者聊天草稿的残留。

> 「LLM 使用统计算法猜测下一个词。结果往往趋向于对最多种情况都成立的、统计上最可能的答案。」
> —— 维基百科 [「AI 写作的迹象」](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)

Humanizer 会标出它找到的每处痕迹，按强度从强到弱排列。它先起草一版改写（不把原文结构当作不可变），再对照模式清单和原文事实检查草稿，最后输出终稿。**它绝不编造内容**。人名、数字、日期、引文、引用或其他事实细节必须来自原文或作者；如果某个句子缺了必要的事实细节，Humanizer 会提问而不是编造。

当你粘贴文本时，Humanizer 会展示它的工作过程：第一版改写、对仍然显得生硬的部分的简短点评、以及最终版本。当你指定一个文件时，它只改散文部分，代码、数据、frontmatter 和链接目标保持不动。个人写作会保留作者的看法和怪癖；技术与参考类文字则保持中性平实。

## 25 种模式

模式按强度和出现频率编号。前 5 种只要出现一处即可判定为需要修改。标了 *单独较弱* 的模式只有在同一段落中出现多处「AI 痕迹」时才计入——因为谨慎的真人作者也可能故意使用其中任何一种。

### A. 摆姿势而不是陈述事实

| # | 模式 | 修改前 | 修改后 |
|---|------|--------|--------|
| 1 | **不是 X 而是 Y** | 「这不只是 X，而是 Y」「这并不意味着 X。它意味着 Y。」 | 直接陈述观点 |
| 2 | **单行收尾和戏剧化断句** | 每节结尾都写「这才是真正的胜利。」；「没有回忆。没有乡愁。」 | 删掉重复的收尾句；把断句合并成具体的论断 |
| 3 | **听起来很深刻的格言** | 「归根结底，重要的是……」「对称是信任的语言」 | 用具体的论断取代格言 |
| 4 | **进入正题前的铺垫** | 「让我们开始吧」「说实话？这得看情况……」 | 去掉铺垫，直接说重点 |
| 5 | **和空气辩论** | 「这主要不是关于……」「一个诱人的做法是……」 | 删掉没人提过的反对意见或虚假选项；保留真实的论断 |

### B. 按规则堆砌节奏

| # | 模式 | 修改前 | 修改后 |
|---|------|--------|--------|
| 6 | **强行三连** | 「创新、灵感与洞见」；三个例子再加一段感悟 | 用意思需要的数量 |
| 7 | **重复的句首** | 「她指出……她指出……她登记……」 | 合并句子或更换主语 |
| 8 | **破折号万能连接**（*单独较弱*） | 「机构——不是人——然而这仍在继续——」 | 改用句号、逗号、冒号或括号；如果样本习惯用破折号则跟随样本 |
| 9 | **堆叠的限定词**（*单独较弱*） | 「可能、也许、或许可以论证地说」 | 只保留原文支持的限定词 |
| 10 | **到处是连字符词组**（*单独较弱*） | 「团队是跨职能的」 | 只保留语法必需的连字符 |
| 11 | **被动语态和缺失主语**（*单独较弱*） | 「无需配置文件」 | 在有助于理解时点明执行者 |

### C. 夸大与借用权威

| # | 模式 | 修改前 | 修改后 |
|---|------|--------|--------|
| 12 | **过度使用的 AI 词** | 「深入探讨……见证……格局……展示……」 | 使用平实的词；SKILL.md 中的词表是唯一的词汇清单 |
| 13 | **夸大重要性** | 「标志着关键时刻」「尽管面临挑战……仍在蓬勃发展」「未来一片光明」 | 保留事实、去掉意义；以最后一个具体事实收尾 |
| 14 | **模糊的联系或关联** | 「与……的领导层有关」「与……有关联」 | 陈述原文给出的具体关系 |
| 15 | **浅薄的 -ing 附属语** | 「象征着……反映了……展示了……」 | 只保留原文支持的部分 |
| 16 | **销售话术** | 「坐落于迷人的地区」 | 直接说这个东西是什么 |
| 17 | **借用权威** | 「专家认为……」「见 NYT、BBC、FT 和 The Hindu 报道」 | 点名真实来源和它的说法，否则删掉该论断或列表 |
| 18 | **回避 is、are、has** | 「作为……存在」「拥有……」「号称……」 | 「是……」「有……」 |

### D. 按规则排版

| # | 模式 | 修改前 | 修改后 |
|---|------|--------|--------|
| 19 | **装饰性加粗** | 「**OKR**、**KPI**」；「**性能：** 性能有所提升」 | 去掉加粗；把标签式列表改写成连贯的散文 |
| 20 | **装饰性标题** | 「战略谈判与伙伴关系」「🚀 上线阶段：」 | 改为句首大写；去掉 emoji 和箭头 |
| 21 | **弯引号**（*单独较弱*） | 他说“这个项目” | 他说 "这个项目" |

### E. 聊天与草稿的残留

| # | 模式 | 修改前 | 修改后 |
|---|------|--------|--------|
| 22 | **聊天机器人残留** | 「好问题！……希望对你有帮助！」 | 去掉外壳，保留内容 |
| 23 | **知识局限声明和猜测** | 「虽然现有资料中的细节有限，但似乎……」 | 陈述资料显示的内容，否则删掉该句 |
| 24 | **标题在第一句重复** | 「## 性能」+「速度很重要。」 | 让标题承担它的职责 |
| 25 | **谈论之前的版本** | 「新增此函数是为了取代……」 | 描述它现在的作用 |

## 完整示例

作者随初稿提供了这些笔记，改写时可以使用：旅行发生在上个十月、酒店在阿尔法玛区、蛋挞是在格拉萨区一家小店吃的、电车坐了大约四十分钟。如果没有这样的笔记，Humanizer 会提问而不是编造。

**修改前（AI 味）：**
> 最近我在里斯本度过了难忘的五天，让我告诉你——这座城市彻底俘获了我的心。从抵达的那一刻起，我就知道自己来到了一个特别的地方。
>
> 坐落于特茹河畔，里斯本见证了葡萄牙人不屈的精神，丰富的历史与现代活力在这里交织。没错，著名的山坡确实陡峭——我的腿深有体会！——但每一次攀登都会用令人叹为观止的全景回报你，让一切辛苦都值得。
>
> 没有坐过标志性的 28 路电车，旅途就不完整，它会带你穿行于这座城市最有历史感的街区。还有美食？简直完美。贝伦区原汁原味的葡式蛋挞是国民宝藏，趁热咬上一口的那一刻，我永生难忘。
>
> 但让里斯本真正特别的不是景色——是那种感觉。从主广场往外走几步，你会发现更安静、更真实的一面：洒满阳光的小巷、迷人的瓷砖立面，以及过着日常生活的友善居民，邀请你慢下来，细细品味每一刻。
>
> 当然，必去的圣若热城堡拥有俯瞰屋顶的绝美视野。排队可能很长，但对历史爱好者或好奇的旅行者来说，绝对值得。
>
> 我还会再去吗？绝对会。里斯本不仅是一个值得游览的地方——它是一个会让你一次次爱上它的地方。如果你正憧憬下一次旅行，这绝对是一个承诺给你一生回忆的目的地。✨

**修改后：**
> 去年十月我在里斯本待了五天，至今心情复杂。美，确实美。但比任何人事先提醒过的都更费膝盖。
>
> 山坡就是全部故事，却不知为何从不进宣传册。我的酒店在阿尔法玛区，拍照很美，实践起来意味着每次想喝咖啡都要爬相当于六层楼的台阶。到第二天，我的小腿已经有了自己的意见。我开始为每次出行规划哪条路是下坡，这是一种奇怪的逛城方式，但可能是最诚实的一种。
>
> 人人都说该坐 28 路电车，我坐了，在陌生人的背包旁挤了四十分钟，期间三个旅游团拍摄同一个街角。下次我会走这条路线，或者早饭前去。不过蛋挞确实名不虚传。我在格拉萨区一家不起眼的小店吃了一枚，还是温热的，大约有三十秒，我理解了为什么有人会为了甜点安排一场旅行。
>
> 我没料到的是，离开主广场后这座城市有多安静。从任何广场往上走两个街区，就是晾衣绳、碎裂的瓷砖、敞开的窗户，还有把足球声音开得很大的老爷爷们。这才是我一直想起的里斯本，不是城堡。
>
> 城堡还不错。视野很好，队伍很长，我花在排队挪动上的时间比进去后看任何东西都多。如果只有两天，我会用它换一个迷路的下午。
>
> 我还会再去，但要等春天，而且要穿更好的鞋。里斯本不会弯下腰来迁就你。我想我喜欢这一点，即使我的腿不同意。
